# Mini Biblioteca
Programa de consola para gestionar una pequeña biblioteca de libros.
## Cómo ejecutarlo
 python main.py
## Participantes
* **Persona A (Etna):** Configuración inicial y estructura del proyecto.
* **Persona C (Asier):** Búsqueda de libros por título o autor (`busqueda.py`).
* **Persona D (Etna):** Guardado y cargado de libros en el archivo (`datos.py`).
